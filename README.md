# Romoj Akhra

A tribal/Santali music streaming site — background illustration, a custom audio-only YouTube player, and category tabs (Old Song, By Year, Cover Song, Instrumental).

Plain HTML/CSS/JS, no build step. See [AGENTS.md](AGENTS.md) for the project structure, local preview command, and deployment details.

Live at [romojakhra.com](https://romojakhra.com).
